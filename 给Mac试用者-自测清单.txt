memory-pack · macOS 自测清单（第一台 Mac）
==========================================

你是我们**第一个跨环境样本**，所以重点不是"成功"，而是"照这份文档能不能做下去"。

【你需要什么】
  · macOS + Python 3.9 或更高（终端里 `python3 -V` 看一眼版本号）
  · 不需要装任何包、不需要 pip、不联网、不需要管理员权限

【要做的事（照 README.md 做，不用管内部实现）】
  1) cp -r memory-pack demo-pack
     cd demo-pack
  2) python3 -B -X utf8 fixture/make_fixture.py ../demo-state
  3) README.md §3 的四步，一步一步敲。每步都记下 **命令 + 退出码 + 原始输出**
     （退出码用 `echo $?` 取；原始输出整段留着，别只留最后一两行）
  4) README.md §4 那两条测试
  5) 最后照 README.md §9 自查：确认 demo-pack 目录跑完没变

【只要发回这些】
  · 每步的命令（原样，别"整理"）
  · 每步的退出码
  · 每步的原始输出（整段贴）
  · 卡住的那一刻：你敲了什么、屏幕上出现了什么、你猜是为什么
  · 你的 python3 版本（python3 -V）＋ macOS 版本（sw_vers）

【特别想知道的一件事】
  README §11 写着：文件锁在 macOS 上走的是 `fcntl` 那一支，
  而**这一支从没有在真机上跑过**（写这版时唯一的机器是 Windows）。
  如果你照 README 把四步跑下来了，这就是那一支**第一次被真跑过** ——
  所以请明确说"跑通了"或者"哪一步炸了、炸在哪"。

【不用做的事】
  · 不用读代码、不用改任何文件、不用装东西
  · 不用把 12 个子命令都试一遍（README §5 那张表是 Windows 实测的）
  · 不用跑 cmd/PowerShell 那两条（那是 Windows 的）

【如果卡住了】
  卡住**不是你的问题**：要么是我们文档没写清，要么是 macOS 上真有一条没测过的路。
  两种都是我们特别想要的信息。请照上面"只要发回这些"发回来即可。
