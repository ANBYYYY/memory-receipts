memory-pack · 给试用者的一页
============================

这是什么
--------
一个很小的程序（纯 Python 标准库，不用装任何东西、不用联网），帮你把"当前状态"
存成一份**唯一卡**，并在中断 / 压缩 / 换会话之后告诉你：恢复出来的东西是不是真的
——它证明"这一版确实存在"，不替你判断内容对不对。

怎么跑（5 分钟，不会污染你现有的东西）
--------------------------------------
0. 需要 Python 3.9 以上。先自检：
     Windows : py -3 -V
     macOS/Linux : python3 -V

1. 把这个目录整个**复制到别处**（别在原目录里跑演示）：
     Windows : xcopy /E /I memory-pack demo-pack
     macOS/Linux : cp -r memory-pack demo-pack
   然后 cd 进去。

2. 照 README.md 的 §2 → §3 敲。（§3 是四步：写入 / 中断恢复 / 迟到候选被拒 / 原文追溯；
   每一步都写了"期望退出码"，对不上就是没过。）

3. 想看测试就跑 README.md §4（35 项）。

跑完你会发现：你手上那份包**一个字节都没变** —— 状态全落在包外的 demo-state/。
macOS / Linux 的完整跑法在 README §0 与 §3 里各有一份（Windows 那份也在）。

卡住了怎么办
------------
把你敲的**命令 + 退出码 + 原始输出**贴回来就行。不用解释、不用总结、不用自己诊断。

三行反馈口（照抄这三行填）
--------------------------
  1) 我用它干了什么活：
  2) 哪一步卡了（没卡就写"没卡"）：
  3) 第二天我又打开它了吗（打开了 / 没有 / 忘了）：

几句话的边界（免得你误解）
--------------------------
  · 它不调用模型，不做数据库 / 向量检索 / 图谱。
  · 它**不保证**宿主自动触发；"手动 resume 成功"不等于"自动恢复被证明"。
  · **macOS / Linux 目前没有实测过**（写这版时手上没有那两台机）；Windows 实测过。
  · 许可 = MIT，署名＝**记性好的大肥鱼姐姐**（LICENSE 的版权行就是这个名字）。
  · 将来要放的仓库名（建议）＝ memory-receipts；**目前还没上传**，所以现在只有这个 zip。
  · 有问题不是你的问题 —— 多半是我们文档没写清，那正是我们要的信息。
